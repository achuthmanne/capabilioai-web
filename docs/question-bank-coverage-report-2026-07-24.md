4. Re-run the coverage query (§7) to confirm the gate is met before flipping any flag.

## 7. How to regenerate this report

```sql
SELECT domain, count(*) AS total,
  count(*) FILTER (WHERE difficulty <= 2) AS easy,
  count(*) FILTER (WHERE difficulty = 3) AS medium,
  count(*) FILTER (WHERE difficulty >= 4) AS hard,
  count(*) FILTER (WHERE review_status = 'approved') AS approved,
  count(*) FILTER (WHERE review_status = 'draft') AS draft
FROM question_bank
GROUP BY domain
ORDER BY domain;
```

Or call the admin API directly: `GET /admin/question-bank/coverage` (requires
`profiles.is_admin = true`), which computes the same aggregation server-side.
